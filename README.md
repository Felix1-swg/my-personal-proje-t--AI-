# Aremu Eatry - Online Food Ordering Website

A responsive website for ordering swallow foods online, built with HTML, CSS, Bootstrap, and JavaScript.

## Features

- Responsive design using Bootstrap
- Soft color animations and hover effects
- Interactive menu with add to cart functionality
- Order form with validation
- Smooth scrolling navigation

## Menu Items

- Pounded Yam - $15.00
- Eba - $12.00
- Amala - $14.00

## How to Use

1. Open `index.html` in your web browser
2. Browse the menu and add items to your cart
3. Fill out the order form with your details
4. Submit your order

## Technologies Used

- HTML5
- CSS3 (with animations)
- Bootstrap 5
- JavaScript (ES6+)

## Browser Support

Works in all modern browsers that support ES6 features.

## Troubleshooting

- If animations don't work, ensure your browser supports CSS animations
- For mobile responsiveness, test on different screen sizes
- JavaScript must be enabled for cart functionality
